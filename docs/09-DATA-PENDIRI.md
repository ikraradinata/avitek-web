# Data Pendiri AVITEK KUKM

Lembar isian untuk menambah kartu pendiri di halaman `/id/tentang/pendiri` dan `/en/about/founders`. Total pendiri: **19**. Nomor 1–4 sudah tayang.

Satu baris = satu kartu. Setelah baris terisi dan izinnya ada, minta Claude Code memasukkannya ke `src/config/founders.ts` dan kedua file messages. Kartu penanda "pendiri lainnya" otomatis berkurang.

## Aturan isi
- **Nama dan gelar** ditulis persis seperti yang diminta pendiri; tidak diterjemahkan.
- **Peran di AVITEK:** misalnya Pendiri, atau Pendiri & Ketua.
- **Jabatan dan institusi** dalam ID dan EN. Jika hanya ada satu bahasa, Claude membuat draf bahasa lainnya untuk disetujui.
- **Foto:** persegi, minimal 800×800px, wajah di tengah, latar polos. Simpan di `public/founders/<slug>.jpg`.
- **Izin:** persetujuan tertulis pendiri (email atau pesan) untuk menampilkan nama, gelar, jabatan, dan foto. Tanpa izin, kartu tidak ditayangkan.
